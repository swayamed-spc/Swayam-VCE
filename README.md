## 📌 HOW TO USE THIS

1. **Create the file** at the root of your monorepo: `README.md`
2. **Replace placeholders:**
   - `your-org` → your GitHub org name
   - `yourcollege.edu` → your actual college domain
   - `tech@ecell.yourcollege.edu` → real contact email
3. **Create `docs/` folder** and add:
   - `ARCHITECTURE.md` (from earlier architecture doc)
   - `API.md` (endpoint list)
   - `DESIGN_BRIEF.md` (design doc)
   - `DEPLOYMENT.md` (deployment steps)
4. **Create `.env.example`** files in both `apps/frontend` and `apps/backend` with placeholder values (no real secrets)
